Entry for the [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) bounty on make.fun.

`main.py` writes one emoji to `/output/entry.txt`:

> 🗻

Mount Fuji at dawn — one specific dream trip, not any holiday: Japan, the climb, the sunrise above the clouds. The field will be flooded with beaches, palms and planes; a snow-capped mountain at dawn is the fresh pick, and it reads instantly at any size on any screen.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
